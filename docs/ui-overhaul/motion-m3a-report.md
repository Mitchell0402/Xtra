## 1. 做了什么

1. **头部在外、分段在 `HorizontalPager` 里**（S4）：游戏页从“一个网格装头部 + 列表”改成“头部 + 分段按钮占位 + 翻页区”。`beyondViewportPageCount = 0`，只有在翻页过程中才组合相邻页。
2. **头部折叠用嵌套滚动驱动**（共同规则 3）：`GameHeaderScroll` 挂在翻页区外面，任何一页的网格往上滚，头部先收到栏下面再滚列表；滚到列表顶部继续往下拉，头部再出来，然后才轮到下拉刷新。头部偏移是全页共用的，切页时不展开（和 v0.1 的 AppBarLayout + ViewPager 一样）。规则是纯函数 `GameHeaderRules`。
3. **每段一个网格，状态在页外**（共同规则 1、X2）：三个 `LazyGridState` 在 `GameScreen` 里（翻页区之外），页面不在时也记得各自的滚动位置。分页流的收集仍在 `GamePage`（`Destination` 层）。
4. **“分段访问过”开关**（审阅 2 N3）：`GamePagerViewModel.openedSegments`。冷启动只开当前分段；手指一开始拖向下一个分段（`pagerState.targetPage` 变化）就打开它，加载和翻页同时进行，那一页先显示骨架。没开的分段传 `emptyFlow()`，刷新和断网恢复对它们是空操作。以前游戏页一打开三个列表同时加载，现在只加载看到的。
5. **分段按钮的高亮块跟手**：`SegmentedControl` 新增可选的 `position`（页面位置 + 偏移比例），在布局阶段读，翻页时不重组分段按钮；没传就照旧点了才滑。
6. **S7 横滑误触**：翻页容器接管横向手势后，卡片上的横滑不再触发点击（`aSwipeOverACardDoesNotOpenIt`）。
7. 删掉了旧的“切分段时滚到第 1 项”的逻辑（每段有自己的网格了）。
