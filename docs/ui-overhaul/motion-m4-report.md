# 动效 M4 报告

日期：2026-11-18。计划：`docs/ui-overhaul/motion-audit.md`（修改版 2，已批准）第 5 节 M4。分支 `motion/m4`。

## 结论

| 验收项 | 结果 |
| --- | --- |
| JVM 测试 | 723 项全过（M3c 时 719；新增 `ChatMotionTest` 4 项）；聊天原有的交互和截图测试不改照过 |
| 动效守护 / lint | 0 问题 / 通过 |
| 模拟器 | 没录：模拟器上的 debug 包没登录，聊天没有输入框、也等不到突袭/投票/竞猜，“我的”页也没有收藏和下载；这些都放进手机 1（M5 合完后） |

## 1. 做了什么

1. **聊天里的条展开/收起**（C4、C5）：突袭、投票、竞猜三条，房间模式标签，@ 提示行，都改成 `AnimatedVisibility` + `expand`/`collapse`（回复条本来就是）。收起时条里保留最后的内容（`rememberLast`），不会先变空再收。条里没有持续动画：倒计时仍是每秒变一次的文字（M0 的毛玻璃守护）。
2. **表情面板 ↔ 键盘**（C6）：
   - 记住的键盘高度改成“这一次弹出过程里最高的读数”。以前每次布局都写入，键盘收起途中的读数会把它越写越小，面板就退回 260 dp 的下限。
   - 面板直接用这个高度（没见过键盘时用 260 dp），不再夹在 260–360 dp 之间，和键盘一样高。
   - 两者共用一块空间：面板（或它让出的位置）的高度 = 记住的键盘高度 − 此刻键盘露出的高度（`EmotePanelRules.space`）。点表情按钮时键盘往下收，面板跟着长出来；点键盘按钮时键盘往上升，面板的位置跟着缩（`panelHandOff`，键盘到顶或消失时结束）。两种方向输入框都不跳。键盘每帧的高度来自聊天已有的全局布局监听（宿主在键盘动画时每帧重新摆聊天）；没有用实验 API。
3. **进入直播时历史消息跳动**（C7）：按计划要先在手机上确认是不是只在模拟器上出现，放进手机 1。
4. **用户会增删的列表加 `animateItem`**（L4）：新的 `LazyGridItemScope.userListItem()`（淡入、steady 弹簧移位、淡出，数值都来自 `LagoonMotion`），接在“我的”页的收藏、下载、筛选三个列表上（这三个本来就有按数据库 id 的稳定 key）；删掉一项（含可撤销的删除）时，后面的项滑上来补位。
   - **没加的**：最近搜索是一个 `FlowRow` 里的标签，不是列表项，不适用；关注页的“频道”列表是分页列表，没有 key，同一频道可能在不同页重复出现（本地关注和账号关注合并），给它加 key 有“重复 key 崩溃”的风险，这次不加；分页加载的长列表按计划不加（L13）。
5. 频道页 M3c 没有走退路，这一条不需要做。

## 2. 留给手机 1

- 登录状态下：突袭/投票/竞猜条的展开收起、表情面板和键盘来回切换时输入框是否完全不动（不同输入法的键盘高度）、C7 历史消息跳动。
- “我的”页删除收藏/下载时的补位动画。
